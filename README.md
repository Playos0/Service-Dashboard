Service-Dashboard

​Service-Dashboard to nowoczesna aplikacja desktopowa służąca do monitorowania oraz zarządzania stanem usług i procesów.
Projekt został stworzony przy użyciu technologii Blazor dla aplikacji desktopowych (Blazor Desktop / Hybrid),
co pozwala na budowanie bogatego, interaktywnego interfejsu użytkownika za pomocą HTML i CSS,
przy jednoczesnym zachowaniu pełnej wydajności i natywnego dostępu do zasobów systemowych oferowanych przez język C# i platformę .NET.

Funkcjonalności

​Natywna aplikacja desktopowa: Działa w osobnym, dedykowanym oknie systemowym (nie wymaga przeglądarki).
​Nowoczesny interfejs Blazor: Wykorzystanie komponentów Razor (.razor) do budowy dynamicznego, responsywnego i płynnego GUI.
​Monitorowanie i kontrola usług: Centralny panel administracyjny do sprawdzania statusów operacyjnych procesów/usług w czasie rzeczywistym.
​Pełna integracja z .NET: Bezpośredni dostęp do niskopoziomowych API systemu operacyjnego z poziomu kodu C#.

Stos technologiczny

​UI Framework: Blazor (Desktop / Hybrid / Webview)
​Język programowania: C#
​Szablony widoków: Razor Components (.razor, HTML + C#)
​Środowisko: .NET SDK
